# Politica de seguridad

## Versiones soportadas

Se aplican parches de seguridad a la rama por defecto del repositorio.

## Como reportar una vulnerabilidad

No abras un issue publico. Usa el reporte privado de vulnerabilidades de GitHub
("Security" -> "Report a vulnerability") o escribe a security@madkoding.dev con:

- descripcion del problema y su impacto,
- pasos para reproducirlo,
- version o commit afectado.

Se responde en un plazo de 7 dias y se coordina la divulgacion tras publicar el arreglo.
